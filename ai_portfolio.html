Prescription SIG Extraction

Client Engagement: Pharmacy Software Company

A clinical NLP system that converts free-text prescription directions into structured data

Prescription directions (SIGs) arrive as messy, abbreviation-heavy text like "1 tab PO BID PRN." This system turns them into structured fields: dose, form, route, frequency, duration, and special instructions.

  • A 20B-parameter language model interprets the free-text input.
  • A deterministic Python parser validates the output and enforces a consistent schema, so downstream pharmacy systems receive clean, reliable fields.
  • Runs on 100K+ prescriptions with sub-second inference per SIG.

AI Legal Skills Platform (Litigation Practice)

Client Engagement: Solo Litigation Practice

An AI-powered legal skills platform built on Claude for a solo litigation attorney with a heavy active caseload

The platform is organized around five skills. I led two of them and built the evaluation that tests them:

  • Long-record review and summarization: page- and section-aware chunking so every summary point traces back to a source citation.
  • Legal research: a mandatory verification gate before any citation reaches the attorney.
  • Evaluation: an eval suite built from redacted case materials that tests both skills against actual filings and hearing prep, not synthetic examples.
