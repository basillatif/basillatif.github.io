ANALYTICS FRAMEWORK

The analytics framework guides every analytics project I do.

The 4 Steps of the Data Science Pipeline Are:
1) Data Collection
2) Exploratory Data Analysis
3) Data Modeling
4) Insights

The analytics framework is helpful for thinking about what steps are needed when starting an analytics project and thinking through all of the steps that need to be completed for a successful one.
